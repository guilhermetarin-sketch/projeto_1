## ✨ Features

### 🚀 Performance-First Design
- **React.memo()** - Prevents unnecessary re-renders
- **useCallback()** - Optimized event handlers with stable references
- **useMemo()** - Cached calculations and filtered lists
- **Code Splitting** - Tab-based lazy component loading
- **Image Optimization** - Native lazy loading with skeleton placeholders
- **Debounced Search** - Smooth, performant search filtering

### 📱 Mobile-First Responsive
- Optimized for mobile devices (max-width: 448px)
- Safe area inset support for notched devices
- Touch-optimized button sizes
- Prevents scroll bounce on iOS

### 🎨 Modern UI/UX
- **Tailwind CSS** - Utility-first styling
- **Orbitron Font** - Racing-style typography
- **Glassmorphism** - Modern design patterns
- **Dark Mode Ready** - Slate color palette
- **Smooth Animations** - Fade and slide transitions

### 📊 Data Management
- **12 Premium Items** - Full reward catalog
- **7 Sales Metrics** - Performance tracking
- **Real-time Calculations** - Total point projections
- **Search & Filter** - By name and category

### ✅ Comprehensive Testing
- **73 Unit Tests** - 98% code coverage
- **React Testing Library** - User-centric testing
- **Jest** - Test runner
- **Memoization Validation** - Performance checks

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/guilhermetarin-sketch/score-brazzo.git
cd score-brazzo

# Install dependencies
npm install

# Start development server
npm start
